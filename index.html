Project Overview

What Is the ME210 Curling DROID?

The goal of the project is to design an autonomous DROID that can compete in a head-to-head curling competition, placing pucks as close as possible to the center target. The robot must operate autonomously using sensors, motors, and an Arduino control system.

Key Capabilities

  • Autonomous navigation — operates without any human input after start signal
  • IR beacon orientation — detects 909 Hz infrared beacons to determine field alignment
  • Line following — uses reflective IR sensors to track centerline tape to the scoring zone
  • Puck release — servo-controlled gate releases pucks down a gravity slide
  • Fully integrated mechatronic system — sensing, actuation, and control on a single Arduino platform

Control Architecture

Robot State Machine

The robot is controlled by a finite state machine (FSM). Each state defines a unique behavior, and transitions between states are driven by sensor events.

States

IDLE

Robot waits at the start position for the competition start signal.

SCANNING

Robot rotates in place to sweep for IR beacon signals on both sides.

SEEKING_TAPE

Robot drives forward while hunting for the centerline tape on the floor.

LINE_FOLLOWING

Robot tracks centerline tape toward the scoring zone using PD control.

STOP_AT_LINE

Robot detects the stop line and brakes to halt in the scoring zone.

RELEASING

Servo gate opens and pucks slide down the ramp into the scoring area.

DONE

All pucks released. Robot holds position until end of round.

The robot starts in IDLE, rotates to detect IR beacons during SCANNING, aligns with the centerline, follows tape to the target zone via LINE_FOLLOWING, stops at the scoring line, and releases pucks before ending the run in DONE.

Puck Release Mechanism

Goal

Release pucks reliably into the scoring zone while keeping the mechanical system simple and reliable.

Approach

We designed a servo-controlled gate mechanism that holds the pucks in a magazine and releases them down a gravity slide. When the robot reaches the scoring zone, the Arduino commands the servo to open the gate, allowing pucks to slide freely into the target area.

MVP Design

We chose a 53-degree slide as our MVP solution because it is mechanically simple and reliable. The slide allows gravity to release the pucks once the servo gate opens — no active propulsion required.

IR Beacon Detection

Goal

Determine the robot's orientation relative to the curling field using infrared beacons positioned at the end of the arena.

Approach

Two IR sensors are placed on the left and right sides of the robot. The robot rotates until both sensors detect the beacon signal simultaneously, indicating that the robot is facing directly down the field toward the scoring zone.

A high-pass filter (~48 kHz cutoff) is used to reject ambient sunlight and isolate the 909 Hz beacon frequency modulated onto the carrier.

Line Following System

Goal

Detect and follow the centerline tape to guide the robot from its aligned position toward the scoring zone.

Approach

We use three TCRT5000 reflective IR sensors mounted on the underside of the robot chassis:

  • Left sensor — detects deviation to the left of the tape
  • Middle sensor — tracks the centerline directly
  • Right sensor — detects deviation to the right of the tape

The sensors detect contrast between the black tape and the light-colored curling sheet surface.

Motor Drive System

Goal

Provide controlled, reliable motion for both alignment scanning rotation and forward navigation along the centerline.

Approach

The drive system uses:

  • TT yellow DC motors — one per driven wheel, lightweight and adequate torque for the robot mass
  • L298N dual H-bridge motor driver — controls motor direction and speed
  • Arduino PWM outputs — generate speed control signals to the L298N enable pins

The L298N driver accepts digital direction signals and a PWM enable signal, allowing the Arduino to independently control both motors for differential steering and rotation.

Build Process

The slide and motor mounting brackets were 3D printed, enabling rapid iteration on geometry between test sessions. The main chassis was laser cut from sheet material, providing precise hole placement for motor and sensor alignment while keeping weight low.

All electronics were mounted on the chassis with standoffs, and wiring was routed to minimize interference between the IR sensors and motor drive signals.
